# Contributing

Thank you for helping improve AI Summarization Skill.

## Useful contributions

- Clear examples in Arabic, French, English, or other languages.
- Improvements to the skill instructions or evaluation checklist.
- Reports of ambiguous rules, omissions, or unsupported additions.
- Compatibility notes for AI systems that support skill files or instruction prompts.

## Contribution principles

1. Keep the source text as the only factual authority for the summary itself.
2. Do not add new requirements that encourage outside facts or unsupported interpretation.
3. Preserve the priority order: fidelity, essential ideas, original order and text type, clear independent wording, then target length.
4. Keep examples short and label synthetic examples clearly.
5. Avoid claiming that a model has been trained by merely reading this repository.

## Suggesting a change

Open a GitHub issue describing the problem, expected behavior, and a small reproducible example. For a pull request, explain what changed and how it improves fidelity or usability.
