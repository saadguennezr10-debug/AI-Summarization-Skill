# Evaluation Checklist

Use this checklist to review a candidate summary. Mark each item Pass, Needs revision, or Not applicable.

## Fidelity
- [ ] Every essential idea in the source appears in the summary.
- [ ] No new fact, explanation, cause, consequence, or conclusion has been introduced.
- [ ] The source's meaning has not been distorted.
- [ ] No opinion, criticism, or personal reaction has been added.

## Structure
- [ ] Essential ideas remain in their original order.
- [ ] The source's text type or pattern is preserved where practical.
- [ ] Tense and pronoun relationships remain accurate.
- [ ] The summary is coherent and cohesive.

## Concision and language
- [ ] Repetition and non-essential details are removed.
- [ ] The wording is independently constructed rather than copied sentence by sentence.
- [ ] Grammar, spelling, and punctuation are correct.
- [ ] The summary is approximately 25–33% of the original word count where feasible.

## Image reliability
- [ ] Text extraction is based only on readable content.
- [ ] Unreadable words were not guessed.
- [ ] A clearer image was requested if the source could not be read reliably.

## Decision rule

A summary fails review if it invents information, changes meaning, or omits a core idea. The word-count target is secondary to fidelity.
